Commands

Comandos

Comandos principales para abrir el menu y aplicar, quitar o restablecer tu morph.

/morph menu

Abre el menu grafico para buscar y previsualizar morphs disponibles.

/morph set <mob_o_bloque>

Aplica el morph indicado directamente por comando.

/morph clear

Quita el morph actual.

/morph normal

Vuelve a tu forma de jugador normal.

Tutorial Rapido

Guia simple para empezar como en la pagina del proyecto.

  1. Descarga Morphy para tu version de Minecraft y tu loader.
  2. Entra al mundo o servidor y abre el chat de comandos.
  3. Abre el menu con /morph menu y busca el mob o bloque que quieras.
  4. O aplica un morph directo con /morph set zombie.
  5. Vuelve a tu forma normal con /morph normal o quita el morph con /morph clear.
